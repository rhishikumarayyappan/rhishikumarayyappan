**MSc capstone: portable ASL word + emotion recognition on CPU.**

MediaPipe Holistic keypoints → calibrated **Bi-GRU** exported to **ONNX**. Privacy-first: only keypoints are processed, never raw video.

- 🎯 **Top-3 accuracy 92.3%** (signer-independent, WLASL)
- ✅ **100% precision** on kept predictions via abstention
- ⚡ **~27 ms** inference on a laptop CPU
